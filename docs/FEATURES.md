## Evidence limitations and reading rules

- The test receipts above are the audit reports' deterministic results at this checkout; compatibility evidence is mock/translator based. No retained live-account run against current Claude Code, Codex CLI, Claude Desktop, or ChatGPT desktop is claimed.
- Smoke scripts can collide on fixed ports. The subscription fallback script passed with isolated ports; failures caused by occupied default ports are harness/environment evidence, not a confirmed protocol regression.
- Landing locations identify current copy, not endorsement. Several shipped capabilities are intentionally hidden from the landing page; broad landing claims must not be expanded beyond the source caveats in this matrix.
- Do not infer stable-release availability from `Cargo.toml`'s `0.2.1` alone. At this branch, use **main only** unless a separately verified `v0.2.1` tag/artifact is available.
