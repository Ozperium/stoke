Clear boundaries

Useful without pretending it is magic.

The public site should make the product easier to evaluate, not make commitments on behalf of a system that is still being prepared.

Is Stoke Cloud live?

No. Stoke Cloud is not deployed yet. The Cloud page describes a proposed private pilot and states its public availability and boundaries; there is no private intake form.

What is free in the pilot?

The first 10 accepted participants can receive 30 days of Cloud access at no charge. That does not promise free hardware, electricity, or third-party model-provider bills. There is no public checkout, payment collection, or card processing.

Does Stoke ship models?

No. Stoke routes to model capacity you configure or that an accepted Cloud pilot explicitly makes available. It does not ship a model catalogue or provider credits.

Can I use the product today?

Yes: Stoke itself is self-hosted and open source. Start with the repository and the public guides. Cloud access is a separate, not-yet-deployed pilot.
