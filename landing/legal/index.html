Legal

Stoke is open-source software, not a hosted inference service.

License

Read the MIT License

Scope

Stoke's self-hosted data plane does not receive or retain your prompts, provider credentials, or model traffic. The public site contains documentation and installation files; it does not provide a hosted gateway or account service.

If you submit the Cloud waitlist, the separate endpoint receives your email address, selected solo/team persona, optional use-case description, and consent so a request can be reviewed. The linked server privacy notice explains that purpose, retention for up to 90 days with daily cleanup, Cloudflare processing, and hashed anti-abuse handling. Deleted records may remain in Cloudflare recovery backups under its retention policies. Waitlist requests are reviewed manually; approval does not automatically grant, start, or email Cloud access. The form remains unavailable until the server confirms the matching privacy-notice version.

Nothing on this site is a warranty that a configuration is secure or suitable for a particular workload. Review the source, test your configuration, and keep credentials out of configuration files where environment variables are available.
