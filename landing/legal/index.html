Scope

Stoke's self-hosted data plane does not receive or retain your prompts, provider credentials, or model traffic. The public site contains documentation and installation files; it does not provide a hosted gateway or account service.

If you submit the Cloud waitlist, the separate endpoint receives your email address, selected solo/team persona, optional use-case description, and consent so a request can be reviewed. Its server privacy notice supplies the actual controller name and contact address before the service is enabled, and states the 90-day expiry, daily cleanup, and Cloudflare processor details. The waitlist remains unavailable until those notice fields are configured.

Nothing on this site is a warranty that a configuration is secure or suitable for a particular workload. Review the source, test your configuration, and keep credentials out of configuration files where environment variables are available.
