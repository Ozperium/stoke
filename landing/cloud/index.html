Preview boundaries

What is — and is not — included.

The pilot is intentionally narrow. These boundaries keep the offer useful without implying capacity, compatibility, or billing promises that have not been verified.

01 / client

macOS Apple Silicon preview

The current preview direction is a macOS Apple Silicon client/runtime shape. Broader desktop compatibility is not promised here.

02 / distribution

Not notarized by Apple

The private macOS preview is not notarized by Apple. Gatekeeper may block it. Any preview installation needs explicit per-file approval; it does not disable Gatekeeper globally.

03 / compute

Owned compute stays yours

The pilot does not promise free hardware, electricity, or third-party provider bills. Cloud access is not a promise of unlimited inference or included external models.

Plain status: Cloud is not deployed yet. Do not send secrets, API keys, prompt contents, or other private details to a public GitHub issue. Read this page for public pilot availability and details; keep evaluation details minimal.
