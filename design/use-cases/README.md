# Use-case illustration sources

The six illustrations are AI-generated concepts, not screenshots or evidence of a running gateway.

- `illustrations/`: selected original local ComfyUI renders.
- `illustrations.json`: prompts, selected seeds, model identity and source/export hashes.
- `social/`: editable 1200 × 630 HTML compositions using the site's own fonts and the matching hero artwork. Render with a 1200 × 630 viewport at device scale 1, after fonts and images finish loading.
- `landing/media/use-cases/`: compressed 1152 × 720 WebP page illustrations and PNG social cards. Frontmatter in `docs/use-cases/` selects the files and alt text.

Keep page art and social art consistent. Bump the asset version when changing a published image so social caches can distinguish it. Run the site generator and the use-case/browser image checks after any change.
