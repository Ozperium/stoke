# Stoke approved OpenDesign presentation contract

Source tokens: ../DESIGN.md. Shared shell/forms: landing/presentation.css. Approved visual: landing/product-visual.css and product-visual.mjs with a deterministic product-visual-model.mjs.

## Routes
- `/`: short promise, approved content-transformation scene, independent Privacy/Budget/Local fallback examples, self-host and optional Cloud actions. No form or promoted film.
- `/cloud/`: same visual language and compact optional-access scene; request-access handoff. No form or readiness essay.
- `/join/`: dedicated real request form; existing notice/consent/no-JS/error contracts unchanged.
- Gateway/Guides/legal/security: existing technical document layout intentionally preserved.

## Control budgets and states
- Buttons: primary, secondary, compact navigation action, illustration playback, scenario choice (maximum5 rendered variants; selected is a state).
- Links: inverse skip, brand, regular, emphasized path (maximum4).
- Input: native email/multiline field (one style); toggles: radio and required consent checkbox (two semantic styles).
- Selected scenario is exposed with aria-selected and roving tabIndex. Arrow/Home/End keys select and focus. Playback has pause/resume/replay, cancels old frames on selection, pauses on document hidden, and becomes instantaneous static explanation under reduced motion.
- Native hidden states always remain hidden. Disabled fields never dim still-active notice links.

## Illustration semantics
Policy is decided before any upstream path becomes active. A refused request never selects an upstream. Connection fallback shows a failed first permitted node before the second permitted node; excluded routes never participate. No mid-stream-resume, model-quality, live-status, latency or production-Cloud claims. Mobile uses a distinct readable composition with the same logical state.
